# Система управления персоналом «Всё записано»

Выполнены задания 1–7 и дополнительные задания 6* и 7*.

- `project.sql` — процедуры, функции, история ставок и триггер.
- `validation.sql` — проверки с тестовыми данными и итоговым `ROLLBACK`.

## Запуск

В новой базе PostgreSQL восстановить исходный дамп курса. Файл
`practicum_sql_for_dev_project_3.sql` фактически имеет формат custom dump:

```sh
pg_restore --no-owner --no-privileges -d hr_project practicum_sql_for_dev_project_3.sql
psql -v ON_ERROR_STOP=1 -d hr_project -f project.sql
psql -v ON_ERROR_STOP=1 -d hr_project -f validation.sql
```

## Правила расчёта

- Повторяющиеся сотрудники в JSON обрабатываются последовательно.
- Проверка 16 часов учитывает сумму часов сотрудника за день во всех проектах;
  флаг устанавливается у добавляемой записи.
- При закрытии проекта учитываются все его логи и все участвовавшие сотрудники.
  Бонусные часы добавляются отдельными записями с текущей датой.
- Зарплата рассчитывается по текущей ставке сотрудника. Оплаченные и требующие
  проверки записи исключаются. Сотрудники без часов к оплате в отчёт не входят.
- Расчёт зарплаты формирует отчёт; флаг `is_paid` не изменяется.
- При одинаковых часах топ учитывает число разных рабочих дат, затем случайный
  порядок. Непроверенные неоплаченные часы сопровождаются предупреждением.

## Проверка

Скрипт выполнен на исходном дампе в PostgreSQL 18.6 (PGlite 0.5.12).
Проверены границы ставок, индексация, бонусы, повторное закрытие, даты и часы
логов, история ставок, топ-3 и переработки. Отчёт за октябрь 2023 дополнительно
сверен независимым расчётом. Параллельные подключения не проверялись.
