# Автосалон «Врум-Бум»

Самостоятельный проект первого модуля «Применение баз данных».
Основное решение — `project.sql`: импорт CSV, нормализация до 3НФ и шесть аналитических запросов в порядке задания. `validation.sql` содержит дополнительные проверки без изменения данных.

## Запуск

Нужен PostgreSQL 15 или новее и пустая база `sprint_1`. Создание базы не включено в итоговый SQL по условию задания.

Скачайте оригинальный [cars.csv](https://code.s3.yandex.net/data-analyst/SQL_dev/cars.csv). Для PostgreSQL в Docker можно использовать существующий `compose.yaml` из корня репозитория:

```bash
docker compose up -d
docker cp cars.csv db:/tmp/cars.csv
docker exec db psql -U postgres -d postgres -c 'CREATE DATABASE sprint_1;'
docker exec -i db psql -X -v ON_ERROR_STOP=1 -U postgres -d sprint_1 < sprint_1/project.sql
docker exec -i db psql -X -v ON_ERROR_STOP=1 -U postgres -d sprint_1 < sprint_1/validation.sql
```

Если запускаете из каталога `sprint_1`, в последних двух командах используйте `project.sql` и `validation.sql` без префикса каталога. Для локального сервера поместите файл в `/tmp/cars.csv` на сервере и дайте процессу PostgreSQL право чтения. Команда COPY использует серверный путь. При ином расположении измените только путь в COPY.

Скрипт не удаляет существующие схемы: повторный запуск требует новой пустой БД. Импорт и заполнение выполняются в транзакции; `ON_ERROR_STOP` останавливает psql при ошибке.

## Структура и решения

- `raw_data.sales` сохраняет все поля CSV и исходный идентификатор. Текст `null` импортируется как SQL NULL, точность исходной цены сохраняется типом numeric.
- `countries → brands → models → cars → sales` разделяет справочники и продажи. `cars` — сочетание модели и цвета, а не физический автомобиль: VIN в источнике отсутствует. Цвета хранятся в `colors`, покупатели — в `customers`.
- Все семь первичных ключей `car_shop` генерируются через IDENTITY. Внешние ключи обеспечивают целостность, UNIQUE исключает дубли справочников. Продажи не дедуплицируются.
- Расход зависит от модели, страна — от бренда; эти значения не повторяются в продажах. Имя не используется как уникальный идентификатор покупателя; используется стабильный телефон из условия.
- Для электромобилей расход остаётся NULL. Неизвестная страна Porsche остаётся NULL и отдельной группой отчёта; страна не восстанавливается предположением.
- Цена продажи уже включает скидку. В нормализованном слое применяется денежный numeric(9,2), как в условии: дробные артефакты CSV округляются до центов. Цена до скидки восстанавливается как `price / (1 - discount / 100.0)`.
- Первый отчёт считает долю из 19 моделей, а не из 1000 продаж или 152 сочетаний модели и цвета. Четвёртый сохраняет повторные покупки и группирует по идентификатору покупателя. Шестой считает покупателей с префиксом `+1` строго по условию.
- В описании указан диапазон 2015–2023, но CSV содержит продажи только с 2015-01-01 по 2022-12-30. Отчёт по брендам выводит все 2015–2023 годы; средняя цена за 2023 равна NULL. Это отсутствие наблюдений, поэтому нулевая цена не подставляется.

## Проверка

Решение полностью выполнено в PostgreSQL 17.5 через PGlite 0.3.16, включая настоящую команду COPY. Для WASM-среды заменён только серверный путь `/tmp/cars.csv` на `/dev/blob`, через который передан исходный CSV. Запуск в Docker/pgAdmin не выполнялся.

Проверены ограничения, количество строк и восстановление всех продаж через `EXCEPT ALL` в обе стороны: пропущенных строк — 0, лишних — 0. Все семь первичных ключей имеют автоинкремент. Результаты шести отчётов дополнительно сопоставлены с независимым расчётом из CSV.

| Таблица | Строк |
| --- | ---: |
| raw_data.sales | 1000 |
| car_shop.countries | 4 |
| car_shop.brands | 7 |
| car_shop.models | 19 |
| car_shop.colors | 8 |
| car_shop.cars | 152 |
| car_shop.customers | 894 |
| car_shop.sales | 1000 |

Контрольные результаты: доля моделей без расхода — 21.05%; покупателей с префиксом +1 — 131. Отчёт по брендам содержит 63 строки (7 брендов × 9 лет), по месяцам 2022 года — 12 строк, списки покупок — 894 строки, цены по странам — 5 групп с учётом неизвестной страны.
